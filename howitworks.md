## Два режима приложения

| Режим                            | Что показывается                                 | Кому                                                                        |
| ------------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| **Оффер**                  | Страница оффера внутри приложения | Пользователям, которые подошли под фильтры |
| **Игра** («фантик») | Обычная игра                                         | Всем остальным                                                     |

Режим определяет сервер по фильтрам, которые настраиваются в админке.

```
Установка приложения
        ↓
Приложение отправляет серверу данные об источнике установки
        ↓
Сервер проверяет пользователя по фильтрам
      ↙            ↘
 Подошёл        Не подошёл
    ↓                ↓
  Оффер            Игра
```

## Что происходит у пользователя

**Первый запуск.** Приложение получает данные об источнике установки (рекламная сеть, кампания и т. д.) и отправляет их на сервер. Ответа ждёт до 15 секунд.

| Ответ сервера                            | Результат |
| ---------------------------------------------------- | ------------------ |
| Пользователь подошёл              | Оффер         |
| Пользователь не подошёл         | Игра           |
| Сервер не ответил или ошибка | Игра           |

**Игра закрепляется навсегда.** Если пользователь один раз получил игру, при следующих запусках приложение не обращается к серверу, и изменение фильтров на него уже не влияет.

**Следующие запуски.**

- Пользователь в режиме оффера продолжает получать оффер. Если ссылка обновилась, открывается новая.
- Пользователь в режиме игры всегда получает игру.
- Без интернета показывается заглушка «Нет интернета».

**Уведомления.** Запрос на включение уведомлений показывается только пользователям в режиме оффера. При нажатии на уведомление открывается ссылка из него (один раз, основная ссылка не меняется).

## Как сервер выбирает ссылку

В админке настраивается список ссылок, у каждой свои фильтры. Сервер проверяет их сверху вниз:

1. Пользователь подошёл под все фильтры ссылки: получает её, остальные не проверяются.
2. Не подошёл: проверяется следующая ссылка.
3. Не подошёл ни под одну: игра.

Следствия:

- Порядок ссылок важен.
- Ссылка без фильтров пропускает всех, поэтому всё, что ниже неё, не сработает.

## Фильтры

### Источник установки

| Фильтр                 | Действие                                                                                                               |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Non-organic countries        | Пропускает только платные установки (не органику) из выбранных стран |
| Organic countries            | Пропускает только органические установки из выбранных стран               |
| Adjust non-organic campaigns | Не пропускает кампанию «Organic»                                                                         |

География

| Фильтр | Действие                                                                                                                |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| Countries    | Пропускает только выбранные страны. Страна определяется по IP-адресу. |
| Languages    | Пропускает только выбранные языки устройства                                            |
| IP ranges    | Чёрный список: не пропускает указанные IP-адреса и диапазоны                   |

### Устройство

| Фильтр             | Действие                                                                                                                             |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| os                       | Пропускает только выбранную систему: Android или iOS                                                      |
| reject if af_ua contains | Не пропускает, если в описании устройства есть выбранное слово (например, iPad) |

### Прочее

| Фильтр                             | Действие                                                                                                                                   |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Block ISP                                | Не пропускает пользователей, в названии провайдера которых есть заданный текст |
| Любой другой параметр | Пропускает, только если значение параметра точно равно заданному                           |

## Если не удалось определить страну или провайдера

Страну, провайдера и признак VPN сервер определяет по IP-адресу через внешний сервис. Если сервис не ответил:

- **Countries**: пользователь не проходит;
- **Languages**, **Block ISP**, **Corporate ISP**: пользователь проходит, так как проверять нечего.

## Пользователи, отказавшиеся от сбора данных

Если пользователь запретил приложению собирать данные, рекламная система не передаёт источник, и он выглядит как органика. В этом случае сервер дополнительно запрашивает источник у Adjust или AppFlyer (настраивается по запросу) и подставляет его в данные установки, чтобы платный трафик не терялся.
